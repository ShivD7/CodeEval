# CodeEval frontend

The React interface for CodeEval.

* Browses weekly problems, the problem library, and club contests.
* Searches by title or topic and filters by difficulty or progress.
* Shows problem statements, constraints, and examples.
* Provides a Monaco editor for C++, Python, Java, and JavaScript.
* Runs samples and shows submission results from the grading backend.
* Autosaves drafts by account, problem, and language.
* Shows solved problems and private submission history.
* Reopens saved code across devices.
* Supports Google sign-in and verified email accounts.
* Includes display-name and password settings.
* Adapts the workspace for smaller screens.

See the [repository README](../../README.md) for the full feature list.
